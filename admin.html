首次设置

需要连接你的 GitHub 仓库，才能「保存并发布」。只需设置一次。
1. 打开 github.com/settings/personal-access-tokens
2. 点 Generate new token（Fine-grained）
3. Repository access 选 Only select repositories，勾选 event-planner
4. Permissions → Contents 设为 Read and write
5. 点 Generate，复制生成的那串令牌，粘贴到下面
